This folder contains the code for the EoMT segmentation model. The original source code can be found here: https://github.com/tue-mps/eomt (MIT licensed)

We only use the code from the `models` folder since we only require the network architecture (click [here](https://github.com/tue-mps/eomt/tree/985630d27fc5adc05afd1a674c0fc0fb307ef928/models) for the source). This reduces the dependencies to a minimum and the code of this folder should work with the standard dependencies listed in the top-level pyproject.toml file.
